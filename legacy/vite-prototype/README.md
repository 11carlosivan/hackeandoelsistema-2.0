# Legacy Vite Prototype

Este directorio conserva el prototipo React + Vite recibido inicialmente.

Uso:

- referencia visual.
- comparacion de pantallas.
- extraccion puntual de ideas o componentes.

No es la base de produccion. La nueva base vive en Next App Router en la raiz del repo.

Antes de rescatar una pieza de este prototipo, validar:

- que no dependa de `HashRouter`.
- que use rutas reales compatibles con WordPress.
- que no use data mock como fuente final.
- que no escriba SEO en cliente con `document.title` o `useEffect`.
- que tenga tests al migrarse.
